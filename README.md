# Safe Graph Contraction for Modularity — COMPSCI 521 research draft

This open capstone repository contains original Python code, fixed study definitions, selected closed evidence, and a [working paper](manuscript/main.pdf). The paper studies exact sufficient conditions for contracting vertex sets before modularity optimization and a specified metric-SDP relaxation. The main package is `src/degree_contraction/`. This is a research draft, not an accepted conference paper or a claim of conference-level novelty.

The [43-case × five-arm formal metric-SDP study](FORMAL-STUDY.md) has finished, and a separate research agent audited all 215 planned outcomes by exact replay. It found 182 exactly verified width targets and 33 wall-limit unresolved outcomes. In the 36 cases where both SD and the stronger SW control reached target, SD was faster in 15 and slower in 21; its median complete-cost ratio was 1.007499. The evidence does not establish a robust complete-cost advantage. The same-block degree/profile condition D is mathematically covered by the full-pair W condition, and the contribution's distinctness from prior improving maps and graph preprocessing remains unresolved. Earlier independent *internal* complete-paper reviews scored a prior version 4/10 (weak reject); internal review is not conference review.

Install the package and test runner in a Python 3.11+ environment with `python -m pip install -e . pytest`. The core code uses NumPy, SciPy, NetworkX and SymPy. Run the included core tests with `python -m pytest -q tests`. Formal metric-SDP tools additionally use CVXPY and SCS; the exact versions are recorded in `experiments/extensions/metric_sdp_formal/formal-freeze.json`. The preview-only import shims for `research/baselines/run_kapoce.py` and `research/full_kapoce/run_full.py` deliberately refuse native execution and never return simulated measurements. Native replication requires upstream GPLv3 KaPoCE and its corresponding source/binary; that upstream code is not bundled here.

The formal [summary and pair rows](FORMAL-STUDY.md) are included, along with source and a raw-file hash inventory. The 1.3 GB formal raw-run tree is **not** on GitHub, so this tree alone cannot rerun the independent raw proof/data audit. Earlier V1/V2 and exploratory closed summaries are in `analysis/results/` and `analysis/runs/`; read each closeout before interpreting its summary. The six-job pilot is a feasibility test, not a comparative result. Original SNAP graph archives and third-party paper PDFs are omitted. Fetch input graphs from URLs in `data/registry.json` and verify the listed hashes; public availability does not itself grant redistribution rights.
