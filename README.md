# Safe Graph Contraction for Modularity — research preview

This repository contains an in-progress COMPSCI 521 capstone research implementation. It studies exact sufficient conditions for contracting vertex sets before modularity optimization and a specified metric-SDP relaxation. The main Python package is `src/degree_contraction/`; experiment and analysis source, dataset provenance metadata, and **closed summary records** are included. This preview is not a conference submission or a claim of conference-level novelty.

The current degree/profile certificate D is mathematically covered, on the same candidate block, by a full pairwise degree-anchor certificate W. Early V1/V2 end-to-end pipeline evidence has not established a robust speed advantage. Two internal complete-paper reviews rated the prior manuscript 4/10 (weak reject) because complete-cost utility and the strength of the joint contribution remain unresolved. The 43-case, five-arm metric-SDP study has completed its fixed measurement schedule, but its independent exact proof/data audit is pending; **this repository contains none of those formal raw measurements or unaudited results**. The six-job pilot included here is a feasibility test, not a comparative result. The exploratory global quotient audit does not establish a general solver guarantee.

The data files here are source URLs, checksums, preprocessing metadata and closed result summaries. Original SNAP graph archives are intentionally omitted: public download availability does not establish redistribution rights. Fetch them from the source URLs in `data/registry.json` and verify their hashes. Full old native KaPoCE-based V1 replication also requires the upstream GPLv3 KaPoCE source/binary; its adapter and vendored tree are not part of this Python-only preview. This preview does not include the live manuscript, third-party papers or the CCFA/Supervisor skill repositories.

Install the package in a Python 3.11+ environment with `python -m pip install -e .`. The code uses NumPy, SciPy, NetworkX and SymPy. `pytest` can run the original package tests; some experiment tests need additional solver/runtime dependencies described in their source directories. The corresponding closed summaries are in `analysis/results/` and `analysis/runs/`; read the accompanying closeout record before interpreting each `summary.json`. The V1 recovery closeout JSON contains a local interpreter path, so this preview carries its prose closeout and summary but omits that raw JSON. This is a staged release: a complete reproduction bundle and the formal metric-SDP outcomes should follow only after independent closeout and a separate public-data audit.
