## 冻结问题与方法

给普通无向无权图和单个 seed，不给目标社团体积，检索 seed 所在社团。CPU 1线程。主方法是 ZR-HFD v1.2：

1. HFD 的同一凸扩散目标，质量从 `3*d_s` 倍增；`sigma=1e-4`。
2. 含 seed 且不拆并列值块的 Z-sweep，`Z(S)=cut(S)/vol(S)+vol(S)/M`。这是已有的 `1−normalized modularity`，不是新目标。
3. 只在第一次扩散支撑非 singleton 后计耐心，连续3档没有超过 `1e-6` 的最优Z下降便停；主质量上限M/2。取最佳档j*，主区域为下一档扩散支撑 `R=supp(x_{j*+1})`，需要时允许补算这一档。
4. R内做冻结 Lovász 比值 MM，每步精确整数 s-t min-cut，严格按精确比值下降接受；另做参数化 seeded min-cut 下凸包，输出区域下界 `LB_R`、`gap=Z(out)−LB_R` 和 `hull-best` 变体。

具体规格见 `provenance/goal-objective.md`。理论定义由 Claude 负责，不得自行改为局部M、新停止规则或另一个目标。建议改动只能提出为另名的 dev 变体，不能替换主方法。真值仅用于离线评价、预登记 oracle 参考和允许的事后诊断。
